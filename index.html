03 / Independent research

Machine learning: models, memory & execution

Independent research engineering · Python, PyTorch, JAX, CUDA & Triton

Designing neural models and memory systems, then turning them into trainable implementations and controlled experiments.

My research spans recurrent language models, learned memory and routing, geometric learning and GPU execution. I build the model code, training and evaluation pipelines, compiler plans and kernels needed to investigate how these systems behave.

Models & memory
State-space architectures, equivariant layers, learned addressing and hierarchical retrieval.
Execution & performance
Parallel scans, CUDA/Triton kernels, custom gradients and hardware-aware execution plans.
Experiments & evaluation
Matched baselines, ablations, held-out cohorts, profiling and reproducible result artifacts.
Explore the research code ↗
Engineering details

The monorepo separates model architectures, learned retrieval, compiler systems and mathematical research into distinct programmes. Memory work compares addressing, update laws and state layouts; compiler work selects execution using shape, precision and hardware profiles. Training kernels include gradient checks, while fused gathered-memory inference is tracked as a separate result. Numerical and exact-arithmetic checks support the wider geometric research.

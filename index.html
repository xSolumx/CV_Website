03 / Applied ML · coursework

Image classification & evaluation

Computer vision · Python, TensorFlow & Keras

An animal-image classifier, with a notebook workflow for preparing data, training the model and inspecting its predictions.

I implemented the image pipeline, convolutional network, validation diagnostics and model save/reload workflow as coursework.

Read the classification notebook ↗
Model & evaluation details

The input pipeline resizes and normalises images, makes a stratified training/validation split, and batches and prefetches data. The Keras network uses convolutional layers, batch normalisation, dropout and L2 regularisation. Loss curves and a confusion matrix describe validation behaviour; the notebook also saves and reloads the model for image predictions.

This is a coursework notebook. Its validation results are not presented as independent test-set performance.

What the work produces

A training pipeline
Labelled photographs become consistently sized, normalised batches for the classifier.
Visible diagnostics
Learning curves and a confusion matrix help identify fitting behaviour and commonly confused classes.
Image predictions
The saved model can be reloaded to assign a category to new images in the notebook.

04 / Independent research

How should a model remember?

Research engineering · PyTorch, JAX, CUDA & Triton

I investigate how neural models retain useful information, learn structure and execute efficiently.

I implement experimental model families, learned-memory mechanisms and the training and evaluation code around them. I also build GPU kernels and model-specific execution plans to study the cost of running those ideas.

Matched baselines and reference checks help separate model behaviour from implementation effects. I compare learning quality, runtime and memory use, and document where an approach helps and where it does not.

Explore the research code ↗
Architectures, execution & evidence

The monorepo contains separate programmes for associative scans, learned memory, equivariant models and controlled benchmarks. Implementations include CUDA/Triton kernels, custom autograd and shape- and precision-aware dispatch. Output and gradient checks compare optimised paths with references; pinned data and artifact manifests keep results traceable. Fused gathered-memory inference is evaluated separately from trainable model paths.
